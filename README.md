# AI Agent Demo

一个从 0 开始学习 AI Agent 的实践项目。

目标：

- 学习 AI Agent 核心原理
- 学习 LLM / Workflow / RAG / MCP
- 实现一个类似 ChatGPT 的 AI Web 应用
- 后续逐步扩展为真正具备工具调用能力的 AI Agent 系统

---

# 技术栈

## Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

## AI / Backend

- OpenAI SDK
- DeepSeek API
- LangChain
- LangGraph
- MCP（后续）
- RAG（后续）
